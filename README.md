# お天気お出かけコンシェルジュ（Weather & Spot Dashboard）

天気予報（時間別・週間予報）と、天候・気温・降水確率に応じたおすすめスポットをリアルタイムに提案するダッシュボードアプリケーションです。

## 特徴

- **7エリア対応の天気予報**: 東京・横浜・京都・大阪・札幌・福岡・那覇の予報データと地域別おすすめスポットを搭載
- **天気シミュレーション（「天気を試す」）**: 快晴・くもり・雨・雪・強風の各コンディションに切り替えて、お出かけ快適指数・服装アドバイス・スポット適合度スコアの動的変化を確認可能
- **時間別グラフ & 週間予報**: 時間帯別の気温曲線と降水確率バーをインタラクティブに表示し、週間予報の日付選択と連動
- **天気適合度スコアリング**: スポットの屋内外属性・耐雨性・適温範囲・天候適性をもとに適合度（%）を自動計算し、悪天候時の屋内バックアップスポットも提案
- **ライト / ダークテーマ切替 & お気に入り保存**: CSS変数ベースのテーマ切替と `localStorage` によるお気に入り永続化に対応
- **依存関係ゼロのクリーン構成**: Node.js 標準モジュール（ESM）と Vanilla CSS のみで構成されており、`npm install` 不要で即座に起動可能

## ディレクトリ構成

```text
weather-spot-dashboard/
├── package.json
├── README.md
├── server.mjs                       # HTTPサーバー & /api/weather プロキシ
├── public/
│   ├── index.html                   # メインHTML
│   ├── styles/
│   │   └── main.css                 # デザインシステム & レスポンシブスタイル
│   └── js/
│       ├── app.js                   # アプリ状態管理・UIレンダリング
│       ├── data/
│       │   ├── weatherData.js       # 天気種別・カテゴリ・都市基本データ
│       │   └── spotsData.js         # 各都市の厳選スポットデータ
│       ├── engine/
│       │   └── recommendation.js    # お出かけ指数・服装提案・適合度計算ロジック
│       └── components/
│           ├── weatherIcons.js      # 天気SVGアイコン
│           └── hourlyChart.js       # 時間別気温・降水確率SVGチャート
└── tests/
    └── recommendation.test.mjs      # 推薦ロジックのユニットテスト
```

## 起動方法

```bash
# 開発サーバーの起動 (http://localhost:3000)
npm run dev

# ユニットテストの実行
npm test
```
